# 第一次制作 PPT

[返回首页](../README.md) · [按工具安装](tools/README.md) · [进阶命令](advanced.md)

## 1. 准备执行环境

本项目需要能读写文件、运行 Python 的 AI Agent。终端准备步骤见[首页](../README.md#快速开始)。核心依赖为 `python-pptx`、Pillow、PyYAML、requests；默认出稿不需要配置图片生成或 TTS API。AI 工具自己的登录与模型访问不由本项目提供。

建议使用仓库内的 `.venv`。以下“Python”均指它的解释器：

| 系统 | 解释器路径 |
| --- | --- |
| Windows | `.venv/Scripts/python.exe` |
| macOS / Linux | `.venv/bin/python` |

无需激活虚拟环境也能执行。请把以下命令中的 `python` 替换成上表路径，或在终端激活后使用。

可先导出仓库自带的四页演示，确认本地转换链路可用：

```bash
python skills/ppt-master/scripts/svg_to_pptx.py examples/quickstart -s svg_output -o .cache/first-demo.pptx -t none -a none
```

这是已有 SVG 的导出，不是自动生成新主题；预期结果是 `.cache/first-demo.pptx`。下载已有产物也可直接[查看演示](../examples/quickstart/demo.pptx)。

## 2. 把主题告诉 Agent

在 AI 工具中打开仓库，发送下面的完整需求：

```text
请读取 skills/ppt-master/SKILL.md，按厦大工作流制作约 10 页 PPT。
主题：校园科研协作。听众：课题组同学。用途：组会讨论。
内容：资料管理、任务分工、进度安排、提交复核。
仅写方案建议，不编造研究数据、引用、姓名或单位。
默认选择适合的厦大模板，使用仓库 .venv 的 Python。
将产物放入独立项目目录；完成检查后给我 PPTX 路径和必要说明。
```

技能根目录为 `skills/ppt-master` 的绝对路径。Skill 文档中的 `${SKILL_DIR}` 是这个根目录的表示方法；Agent 需要自行解析，不能把它当作各宿主都会自动设置的环境变量。

有材料时，把文件放到 Agent 可以访问的目录，说明它是内容来源还是要保留的版式。使用 PDF、Word 等输入时，可能需要按[完整依赖文件](../skills/ppt-master/requirements.txt)安装对应转换依赖。

## 3. 需要保留模板时这样说

```text
使用“厦门大学_主题_凤凰花开”的原生 PPTX 模板，保留原页面样式。
用我提供的材料生成 8 页汇报，允许复用、重排源页。
只使用有依据的内容；放不下就精简或换源版式，不缩成难读的小字。
```

14 套模板均有 SVG 原型；原生填充有 13 套，南强蔚蓝缺少原生源文件。上传旧 PPT 作内容参考不意味着要保留其版式，明确用途能避免选错路线。

## 4. 收到文件后

默认交付 `.pptx` 的路径及内容、验证状态的简短说明，不要求你接收审计报告、JSON、源稿压缩包等额外附件。源稿保留在项目目录，需要时再取。

请用目标软件检查每页的文字、Logo 比例、图表与讲者备注，尤其是最密的一页。自动检查只做结构和近似排版判断。输出文件名可能带时间戳，以日志中的实际路径为准。

## 本机、远程与云端有什么区别

| 环境 | 文件与依赖放在哪里 | 需要留意 |
| --- | --- | --- |
| 本机终端 / IDE / 桌面 Agent | 本机仓库、虚拟环境、输出目录 | Agent 需要执行权限；字体以本机安装情况为准 |
| SSH / 容器 / 远程开发 | 远程主机内的仓库与 Python 环境 | 本机路径不可直接用；生成后需下载 PPTX |
| 云端 Agent | 云端工作区中完整的 Skill、素材和依赖 | 本地 Skill 不会自动同步；依赖安装和文件导出须被环境允许 |
| 无文件执行能力的聊天界面 | 无法直接运行完整链路 | 可先讨论提纲，再交给具备执行能力的 Agent；本项目不提供聊天链接一键安装 |

转换在所在执行环境中运行。发给模型的内容是否上传、保留或用于其他目的，取决于 AI 工具及其设置；不要把本项目的本地脚本理解为所有数据都不会离开电脑。

## 常见问题

**找不到 `ppt-master`？** `skills/ppt-master` 是源码目录，不一定是工具自动发现的安装目录。先用上面的源码调用，或按[对应工具入口](tools/README.md)安装完整目录。不要只复制 `SKILL.md`。

**提示缺少模块？** 先确认 Agent 用的是安装了依赖的那一个 Python。核心依赖不包含所有输入格式转换工具；按实际报错安装所需可选项。

**PPT 能打开但换行不同？** 对照制作与播放机器的字体。仓库不附带字体文件；换字体后重新检查版面，不承诺固定回退到某一种中文字体。

**想只用 Python 输入主题自动生成？** 当前没有这样的独立主题生成命令。脚本需要由 Agent 提供 SVG 页面或填充计划。

**希望做校外或商业展示？** 先检查[素材待核验清单](assets.md)，代码的 MIT 许可不等于校方素材获授权。
