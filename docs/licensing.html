素材边界与授权

最后更新：2026-11-07 · 本项目为非官方个人作品

本站展示的模板包含厦门大学校徽、校名标准字、校园照片与第三方素材。 这些素材不在 MIT 许可范围内，也未取得公开再分发或商业使用的授权证明。

1. MIT 覆盖什么

仓库根目录的 LICENSE（MIT）覆盖：源代码、脚本、工作流，以及为本项目编写的 JSON / SVG 版式定义与模板结构。

2. MIT 不覆盖什么

  • 厦门大学校徽、校名标准字、视觉识别系统素材；
  • 校园照片、人物肖像、第三方插画、纹理与图标；
  • source.pptx 及其内嵌的图片、图形与字体子集；
  • examples/*.pptx 中的学校或第三方素材；
  • 本机外部模板库的原件、预览图与衍生截图；
  • 字体文件（仓库不内嵌字体，字体名称不代表授权）。

3. 允许用途

取值含义
local仅本机个人学习、教学与科研演示；不得公开仓库、网盘或对外分发
public可随公开仓库或公开网页发布
commercial可用于商业交付或收费产品

当前 15 套内置模板全部登记为 unknown / local。只有当 license_status 不是 unknown 且附有证据时，才允许声明 public 或 commercial；仓库的 scripts/check_assets.py 会拒绝违规声明。

4. 权威文件

LICENSE（MIT） LICENSE-ASSETS（素材边界） 授权与边界设计 素材台账 逐套声明 素材核验记录

5. 需要授权时

公开再分发、商业使用或对外交付前，请先取得权利人的书面许可，并在 assets_manifest.json 中登记许可名称、证据与核验日期。若无法取得授权， 请保持 local 用途，或替换为可公开的素材。
