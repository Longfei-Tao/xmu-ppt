## 安装与运行

### 装完技能，Agent 里没出现 `/xmu-ppt`

1. 确认复制的是**整个目录** `skills/xmu-ppt/`，不是只有 `SKILL.md`；脚本、模板、工作流都在同级子目录里。
2. 确认目标路径是宿主认的目录（Claude Code 用户级 `~/.claude/skills/`，项目级 `.claude/skills/`；其他宿主见[工具目录](tools/README.md)）。
3. 开一个新会话再试——技能列表通常在会话启动时读取。
4. 仍然不行就走源码调用：直接在仓库目录里开 Agent，让它读 `skills/xmu-ppt/SKILL.md`，效果等价。

### 报 `ModuleNotFoundError` 或 `No module named 'pptx'`

Agent 用错了 Python。仓库里的脚本必须用装了依赖的那一个解释器跑：

```bash
# Windows
.\.venv\Scripts\python.exe skills/xmu-ppt/scripts/svg_to_pptx.py ...
# macOS / Linux
.venv/bin/python skills/xmu-ppt/scripts/svg_to_pptx.py ...
```

没建过虚拟环境就手动补核心依赖：`pip install python-pptx Pillow PyYAML requests`。

### 没有 Git 能用吗

能。下载 ZIP 解压后同样可用，步骤见[快速开始](quickstart.md)的「没有 Git」一节。只是后续更新要重新下载，不能用 `git pull`。

### 需要联网吗

只在装依赖时需要。装完之后出稿全程本地跑；除非你要求 AI 生图或联网找图，否则不访问网络。

### 用哪个模型

本仓库不调用模型，排版和文案由你选的 Agent 完成，所以任何能读写文件、执行命令的 Agent 都能跑。实践差异主要来自**上下文窗口**：稿子越长，模型越容易忘记 `spec_lock.md` 里的配色与字号，建议 10 页以上用上下文大的模型，或分批出稿后再合并。

## 出稿质量

### 生成的 PPT 里换行和我这边不一样

字体不同。仓库不附带字体文件，SVG 里写的字体栈在别人的机器上会回退。解决方式有两种：让全组统一安装同一套中文字体，或者把字少写一点、留出余量。**上台前一定用实际演示的那台电脑打开检查一遍。**

### 文字挤到边框或装饰上

说明文案超出了版式容量。两条路线的处理方式不同：

- **SVG 出稿**：内容页标题建议不超过 7 个汉字（42px 下再长会撞上 `PART 0X` 标签），正文单行不超过 42 字；超了就拆页，不要缩字号。
- **原生填充**：受源版式槽位约束，容量约为 `槽宽 ÷ 字号 × 0.9` 个汉字每行。超了要改文案或换一个版式页，不能靠自动换行救。

### 能不能只给主题、不给材料

能，默认会写成方案或知识介绍稿。但它**不会**替你编实验结果、统计数字、参考文献和姓名——这类字段要么你给，要么留空。

### 一次要多久

10 页左右的稿子，实测 2–5 分钟出稿并完成 SVG 质量检查与 PPTX 版面体检。首次安装依赖、首次加载模板会更久。

## 模板与素材

### 为什么南强蔚蓝不能原生填充

它的原始文件是 `.ppt`，不是 `.pptx`，无法解析槽位。需要它时走 SVG 出稿；或先用 PowerPoint 另存为 `.pptx`，再用入库脚本重建索引。

### 能拿去商用或校外演示吗

不能直接拿去。代码与模板结构是 MIT，但**校徽、校名标准字、校园照片不在授权范围内**，仅限校内非商业教学科研使用。校外正式场合请换成中性模板，或自行向学校确认授权。详见[素材与许可](assets.md)。

### 模板里的「官方」是什么意思

是早期目录命名，指“按学校视觉规范精修重制”，**不代表学校出品或授权**。因为已被示例、命令和索引大量引用，改名会破坏现有用法，所以保留。

## 维护

### 怎么更新到最新版

```bash
python skills/xmu-ppt/scripts/update_repo.py
```

它会先检查本地改动，**有未提交的修改会拒绝执行**——先 commit 或 stash 再跑；然后拉取最新代码，并且只在 `requirements.txt` 变化时才重装依赖。加 `--skip-pip` 可跳过依赖同步。ZIP 用户重新下载覆盖即可，注意先备份自己改过的模板。

### 我改了模板，更新会不会被覆盖

会。`git pull` 会覆盖同名文件。建议把自己的模板放在独立目录并只改 `templates/decks/` 之外的内容，或先提交到自己的分支。
