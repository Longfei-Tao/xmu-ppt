# 用户选择模板实施计划

目标为生成前由用户选定视觉模板，显式授权后允许 AI 代选。

沿用 confirm_ui 服务生命周期，增加独立的模板选择页面。模板元数据存放于技能目录，公开画廊通过构建脚本取得同源数据和已有预览图。

- [x] 增加模板选择回归测试，覆盖待选择、非法模板、路线限制、过期请求、重复提交。
- [x] 建立 14 套模板索引及选择读写工具，原子保存结果。
- [x] 接入本地确认服务，复用等待与关闭流程。
- [x] 实现共用画廊页面，支持预览、筛选、推荐和明确确认。
- [x] 构建 GitHub 静态画廊，提供复制指令和手动复制降级。
- [x] 更新入口、两条工作流、中英文首页和使用文档。
- [x] 运行测试、模板审计、文档检查及页面验证。

既有项目保持可读。新选择不得覆盖已确认的选择。更换模板应建立新的项目，并经用户授权处理已有产物。源码改动保留在当前 Git 工作区，发布另行处理。

验证记录更新于 2026-11-03。完整回归覆盖全部 14 套 SVG 导出和 13 套原生填充。浏览器检查覆盖桌面、手机、预览、筛选、路线限制、本地确认与公开页面复制指令。
