## 如何理解现有许可证

[LICENSE](../LICENSE) 的 MIT 段适用于代码与模板结构，并明确排除学校及其他第三方素材。既有声明提出的“校内非商业用途”是仓库的使用边界说明，**不能代替权利人授权证明**；即便不收费，也不能仅凭这句话判断可公开镜像或商用。

“厦门大学”在此用于说明目标风格与使用场景。模板 ID 中的“官方”是历史命名，不代表本仓库获得学校授权、审核或合作认可。未发现可支持这些关系的证据，因此首页不作相关宣传。

## 展示策略

新增首页拼图只来自自主创作的四页演示及实际 PowerPoint 渲染，不使用待核验的校方素材。原有模板总览保留在[模板页](templates.md)，注明其性质和许可核验状态；本次未从第三方仓库下载图片、Logo、模板或字体来补齐展示。

维护者后续可按“文件路径 → 原始来源 → 作者/权利人 → 许可原文或书面授权 → 允许的用途 → 核验日期”补齐记录。需要调整待核验资产时，另行确认范围和替代方案，不自动删除或覆盖。
