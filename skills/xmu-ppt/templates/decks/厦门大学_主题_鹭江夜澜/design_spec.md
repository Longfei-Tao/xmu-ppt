# 厦门大学_主题_鹭江夜澜 - Design Specification

> 厦门大学PPT模板 · 深蓝弧波 + 校园夜景 + 巨号章节数字

## I. Template Overview

| 项 | 内容 |
| --- | --- |
| Use Cases | 毕业论文开题、答辩、预答辩、毕业汇报；需要完整六章叙事（选题背景／研究目标／研究内容／研究方法／论文进度／研究成果）的场景 |
| Design Intent | 以深藏蓝弧线为视觉主线，封面与结束页用同一张校园夜景照片和上下白色波浪裁切首尾呼应；内页留白充足，靠巨号章节数字与顶部导航条建立层级 |
| Source | 用户提供的第三方模板 `db68-厦门大学毕业论文开题答辩通用ppt模板.pptx`（70 页，16:9） |

## II. Canvas Specification

- 1280 × 720（viewBox `0 0 1280 720`），16:9
- 源 PPTX 70 页、10 种版式；本套收录 5 页 SVG 原型，原生填充可克隆全部 70 页

## IV. Typography

- majorLatin / minorLatin: `Arial`；minorEastAsia: `等线`
- 源 PPTX 内嵌 3 个字体部件，已按仓库约定在 `source.pptx` 中剥离；渲染依赖本机字体

## V. Logo

- 封面与结束页右上角为厦门大学校徽与校名标准字，内容页顶部导航条含同款标识
- 校徽、校名标准字与校园照片的公开再分发许可**待核验**，见 `docs/assets.md`；不据此声称校方授权

## VI. Page Structure

- 视觉 DNA：上下白色**波浪弧线**裁切、左下／右上深蓝弧块、巨号深蓝章节数字、圆形编号徽标、顶部六段式胶囊导航条
- 内页网格：左右对称双栏、白底细线卡片，页脚右下角页码
- 装饰只由基础几何与一张夜景照片构成，无复杂图表对象

## VII. Page Types

| 角色 | 说明 |
| --- | --- |
| cover | 深蓝夜景照片 + 白色波浪上下裁切 + 校徽 + 白色大标题 + 答辩信息行 |
| toc | 白底 + 六个深蓝圆形编号 + 底部深蓝波浪 + 右上角弧块 |
| chapter | 纯白底 + 巨号深蓝数字 + 章节名 + 左下深蓝弧块 |
| content | 顶部深蓝导航条 + 左右对称细线卡片 / 三栏小标题 |
| ending | 与封面同构的深蓝夜景 + 「敬请各位老师批评指正！」 |

## X. Usage Notes

- 本套模板按 `create-template` 的 mirror 模式一比一转换，页面保留原示例文字；生成新 PPT 时只改文本，不动图形、图片、版式与装饰
- 源模板含第三方作者署名占位（答辩人、导师均为占位文本，已脱敏），使用前必须替换为真实信息
- 换页数时优先复制 `03_content.svg` 做内容页、`02_chapter.svg` 做章节页
- SVG 路线可用 5 页原型，原生填充路线可用全部 70 页；两条路线均需逐页在实际演示软件中检查

## XI. SVG Technical Constraints

1. viewBox 固定 `0 0 1280 720`
2. 只使用基础图形、文本、图片与 `linearGradient`
3. 禁止 `mask`、`<style>`、`class`、`foreignObject`、`textPath`、`animate*`、`script`
4. 图片相对路径引用 `assets/`

## XII. 成稿正文可读性

SVG 原型中的示例小字不作为新写正文的字号标准。1280×720 画布下，新写正文优先使用 24–28px，注释 16–18px；写入项目 `spec_lock.md`，空间不足时拆页或精简。固定页脚、品牌字和原模板装饰文字可保留原尺寸。原生填充保留源样式，交付前需以实际投影用途检查可读性。
