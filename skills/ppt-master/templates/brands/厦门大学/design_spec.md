# 厦门大学 Brand Specification

> Identity-only preset. No SVG page roster — pages are composed freely under these constraints.

## I. Brand Overview

| Property | Value |
|---|---|
| Brand Name | 厦门大学（Xiamen University） |
| Use Cases | 论文答辩、课程汇报、科研组会、成果展示、招生宣讲、校园活动 |
| Tone | 庄重、学术、克制、有人文气，不花哨 |
| Sources | 校徽组合标志（蓝色 `#204080`）；2025 厦大实用风模板「壹 厦园晴日 / 叁 凤栖青橙 / 肆 南强蔚蓝」；办学理念「自强不息，止于至善」 |

| white | `#FFFFFF` | fact | 卡片与反白文字 |

## III. Typography

| Role | Family | Weight |
|---|---|---|
| title | `"华文中宋", "Source Han Serif SC", "思源宋体", "SimSun", serif` | 600–700 |
| body | `"微软雅黑", "Microsoft YaHei", "Source Han Sans SC", "思源黑体", "PingFang SC", sans-serif` | 400 |
| numeric | `"Manrope", "Inter", Arial, sans-serif` | 600–700 |

> 正式答辩与学术汇报优先使用宋体标题（华文中宋），正文用微软雅黑保证可读性；现代风格页面可把标题切换为思源黑体，但同一份演示中不要混用两种标题气质。

## IV. Logo

| File | Form | Usage |
|---|---|---|
| `./xmu_logo.png` | 校徽 + 中英文校名横向组合（289×83，透明底） | 封面左上角、结束页、内容页右上角 |

- 位置：封面固定左上角；内容页固定右上角；一章内保持一致
- 尺寸：封面宽 240–270px；内容页宽 140–170px；结束页宽 260–320px
- 最小宽度 120px，不得拉伸变形、不得改色、不得加描边或阴影
- 留白：四周至少留 0.5 倍徽标高度，禁止压在照片的复杂纹理上
- 深色底上不要直接放蓝色校徽；改用白色文字校名或先垫浅色卡片

## V. Voice & Tone

- Formality: formal（面向导师、评委、同学）
- Person: 我们 / 各位老师
- Emoji: forbidden
- Abbreviations: 首次出现写全称，后续可用简称（如「厦门大学」→「厦大」）

## VI. Icon Style

- Preference: linear

> 线性图标与学术场景更协调；装饰性图形优先使用厦大自有元素（凤凰花、黑天鹅、嘉庚建筑、绿瓦屋顶），不要使用通用商业插画。
